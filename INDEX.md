## 📱 Testing Checklist

**Desktop (1025px+)**
- [ ] All 4 columns visible
- [ ] Navigation normal
- [ ] Hero 100vh height

**Tablet (768-1024px)**
- [ ] 2-column layouts
- [ ] Mobile menu visible
- [ ] Hero 70vh height

**Mobile (480-767px)**
- [ ] Single column
- [ ] Hamburger menu works
- [ ] Touch targets large

**Small Mobile (<480px)**
- [ ] Fully responsive
- [ ] No horizontal scroll
- [ ] All text readable
